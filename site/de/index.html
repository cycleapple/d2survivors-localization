Installation

Du änderst keine Spieldateien von Hand – das erledigt der Launcher. Schließe vorher das Spiel. Der Launcher zeigt alles in der Sprache an, die du auswählst.

  1. Zuerst D2 Survivors installieren

    Lade die Desktop-Version von der offiziellen D2-Survivors-Website, gib im Einrichtungsbildschirm deinen Diablo-II-Ordner an und prüfe, ob das Spiel startet.

  2. Launcher herunterladen

    Lade d2s-launcher.exe herunter und lege ihn in einen beliebigen Ordner. Keine Installation nötig.

  3. Sprache wählen

    Beim ersten Start siehst du alle Sprachen, jede in ihrer eigenen Schrift. Klicke auf deine Sprache und dann auf „→“ – Launcher und Spielübersetzung nutzen ab dann diese Sprache.

  4. Den Assistenten in drei Schritten durchgehen

    ① „Spiel“: Der Launcher sucht D2 Survivors (standardmäßig in %LOCALAPPDATA%\Programs\D2 Survivors; liegt es woanders, nimm „Ordner wählen…“). ② „Diablo II“: Er sucht dein Diablo II: Resurrected oder klassisches Diablo II; wird nichts gefunden, kannst du „Überspringen“. ③ „Fertig“: Auf Wunsch „Desktopverknüpfung erstellen“, dann „Spielen“. Beim ersten Mal wird die Übersetzung geladen und die originale app.asar gesichert.

  5. Danach über die Verknüpfung oder den Launcher starten

    Standardmäßig holt jeder Start die neueste Übersetzung („Übersetzungen beim Start aktualisieren“ unter „Einstellungen“), und nach Spiel-Updates wird sie automatisch neu angewendet. Die Sprache wechselst du im Hauptfenster unter „Spielsprache“.

Original wiederherstellen

  • Klicke im Launcher unter „Einstellungen“ auf „Originalspiel wiederherstellen“, dann ist die originale app.asar wieder da.
  • Um eine Weile auf Englisch oder Koreanisch zu spielen, wähle unter „Spielsprache“ English oder 한국어 und starte – das ist das unveränderte Original.
  • Alles entfernen: erst das Original wiederherstellen, dann den Launcher, die Desktopverknüpfung und den Ordner %LOCALAPPDATA%\D2SurvivorsLauncher löschen.

Desktop-Verknüpfung

Für eine eigene Verknüpfung nimm diese Zeile als Ziel: Das Spiel startet direkt in der gewählten Sprache, ohne Launcher-Fenster. (Die Verknüpfung aus „Desktopverknüpfung erstellen“ öffnet das Fenster und startet das Spiel sofort.)

d2s-launcher.exe --launch --lang de
--launch
Sprache anwenden und Spiel starten
--play
Launcher-Fenster öffnen und das Spiel sofort starten (nutzt die Desktopverknüpfung)
--lang <id>
Sprache: zh-TW, zh-CN, ja, de, fr, ru, pl oder das Original en, ko
--no-update
Diesmal nicht nach Updates suchen
--update
Nur die Übersetzung aktualisieren
--restore
Original wiederherstellen
--self-update
Den Launcher selbst aktualisieren
--status

Lesezeichen holen

Du spielst im Browser auf d2survivors.lol? Ein Lesezeichen stellt das Spiel auf Chinesisch (traditionell), Chinesisch (vereinfacht), Japanisch, Deutsch, Französisch, Russisch oder Polnisch um, mit derselben Übersetzung wie der Launcher. Keine Installation, auf PC und Handy.

Vorankündigung: Auf dem Handy lässt sich bald womöglich nicht mehr spielen. Laut dem Entwickler von D2 Survivors stellt die Browser-Version die Spieldateien („Hosted files“) bald nicht mehr bereit; ein Datum gibt es nicht. Danach können Touch-Handys und Tablets keinen Diablo-II-Installationsordner lesen und zeigen nur noch eine Seite „nicht mehr verfügbar“ – spielen geht dann nicht. Am Computer wählst du zuerst auf der Einrichtungsseite des Spiels „USE MY OWN FILES…“ (eigene Dateien verwenden) und gibst deinen D2-1.14- oder D2R-Installationsordner an; danach funktioniert das Lesezeichen wie gewohnt. Die Desktop-Version ist nicht betroffen.

So funktioniert es

  • Benutze das Lesezeichen auf der Startseite d2survivors.lol, dann startet das Spiel direkt auf Deutsch. Die Startseite braucht weniger Arbeitsspeicher und lädt schneller, besonders auf dem Handy zu empfehlen. Auf der Spielseite (/play/) geht es auch: Das Spiel startet übersetzt neu und speichert vorher, auch mitten im Lauf.
  • Das Lesezeichen von dieser Seite öffnet fest Deutsch. Für eine andere Sprache legst du das Lesezeichen auf der Seite dieser Sprache an; wer es schon früher angelegt hat, muss es neu anlegen, damit die Sprache fest eingestellt ist. Unter „Optionen → Einstellungen“ im Spiel kommen außerdem Chinesisch (traditionell), Chinesisch (vereinfacht), Japanisch, Deutsch, Französisch, Russisch und Polnisch dazu; auf dem Handy wechselst du die Sprache aber besser über das Lesezeichen.
  • Ein weiterer Klick bringt dich zurück zur englischen Originalspielseite. Neu laden bringt ebenfalls das Original zurück; für die Übersetzung einfach das Lesezeichen erneut benutzen.
  • Ruckelt das Spiel auf dem Handy, wird es heiß oder lädt es oft von selbst neu, schalte im Spiel unter „Optionen → Grafikoptionen“ „Energiespar-Grafik“ ein: Die Auflösung sinkt, das Spiel läuft flüssiger und kühler, das Bild wird etwas weicher.
  • Spielstände bleiben wie gewohnt im Browser. Das Lesezeichen lädt jedes Mal die neueste Übersetzung von dieser Website, braucht also eine Internetverbindung.

FAQ

Ist das eine offizielle Übersetzung?

Nein. Es ist eine inoffizielle Fanübersetzung ohne Verbindung zu den Entwicklern von D2 Survivors oder zu Blizzard Entertainment.

Ist das Open Source?

Der Code schon. Der Quellcode von Launcher, Lesezeichen, Website und Werkzeugen liegt auf GitHub unter der MIT-Lizenz. Der Launcher wird von GitHub Actions automatisch aus diesem öffentlichen Quellcode gebaut (Build-Verlauf), und jedes Release enthält d2s-launcher.exe.sha256, damit du ihn selbst prüfen kannst.

Wie weit ist die deutsche Version?

Sie ist fertig: vollständig übersetzt und im Spiel auf Lücken geprüft. Danach wurden alle Oberflächentexte und 300 zufällig gewählte Einträge noch einmal unabhängig gegengelesen; daraus entstanden rund 400 Korrekturen im ganzen Wörterbuch. Namen magischer Gegenstände und besonderer Monster werden nach deutscher Grammatik zusammengesetzt, etwa „Robuste Kappe des Geistes“, und Heldinnen tragen weibliche Titel. Rund 70 % der Begriffe stammen direkt aus der offiziellen deutschen Übersetzung von Diablo II: Resurrected.

Kann ich auf Mac, Linux oder dem Handy spielen?

Ja. Den Launcher gibt es bisher nur für Windows; auf Mac, Linux und Handy spielst du die Browser-Version und nimmst das Lesezeichen aus dem Reiter „Browser“.

Hinweis: Laut dem Entwickler stellt die Browser-Version die Spieldateien bald nicht mehr bereit (noch ohne Datum). Danach lässt sich auf Handys und Tablets nicht mehr spielen; am Computer wählst du auf der Einrichtungsseite des Spiels deinen eigenen Diablo-II-Installationsordner.

Der Entwickler entfernt die bereitgestellten Spieldateien. Was ändert sich?

Die Browser-Version von D2 Survivors fragt jetzt vor dem Start, ob du deine eigenen Dateien (einen D2-1.14- oder D2R-Installationsordner auf deinem Computer) oder „Hosted files“ von der Website verwenden willst. Laut dem Entwickler fallen die Hosted files bald weg; ein Datum gibt es nicht.

  • Handys und Tablets: Sie können keinen Installationsordner lesen. Sind die Hosted files weg, zeigen sie nur noch eine Seite „nicht mehr verfügbar“, spielen geht nicht. Das ist eine Änderung am Spiel selbst, das Lesezeichen kann daran nichts ändern.
  • Computer: Wähle auf der Einrichtungsseite „USE MY OWN FILES…“ (eigene Dateien verwenden) und gib deinen Spielordner an, danach nutzt du das Lesezeichen wie gewohnt.
  • Desktop-Version: Sie liest ohnehin die Spieldateien auf deinem Computer und ist nicht betroffen.
Werden meine Spielstände verändert?

Nein. Der Launcher ersetzt nur resources\app.asar im Spielordner und sichert vorher das Original. Spielstände liegen woanders und werden weder gelesen noch geändert.

Werden meine Spielstände verändert?

Nein. Spielstände bleiben wie gewohnt im Browser. Das Lesezeichen tauscht nur den Text des Spiels in der geöffneten Seite aus und hinterlässt nichts; neu laden bringt das Original zurück.

Was passiert bei einem Spiel-Update?

Ein Update ersetzt app.asar, die Übersetzung ist dann weg, bis du das Spiel wieder über den Launcher oder die Verknüpfung startest – der wendet sie erneut an.

Hat sich die neue Version zu stark geändert, erzwingt der Launcher nichts: Er startet das Originalspiel und meldet, dass die Übersetzung angepasst wird. Ist sie fertig, wird sie beim nächsten Start automatisch wieder angewendet – du musst nichts tun.

Was passiert bei einem Update der Browser-Version?

Das Lesezeichen prüft jedes Mal, ob seine Regeln zur neuen Version passen. Wenn nicht, meldet es, dass die Übersetzung ein Update braucht, und startet nicht; das Originalspiel bleibt unberührt. Spiel bis zum Update hier auf Englisch.

Warum steht im Sprachmenü des Spiels meine Sprache statt Koreanisch?

Die Übersetzung nutzt den eingebauten Koreanisch-Platz des Spiels. Danach zeigt das Menü dort den Namen der gewählten Sprache. Für Koreanisch wähle im Launcher „한국어 (원본)“.

Auf dem Handy passiert nichts, wenn ich das Lesezeichen antippe?

Android Chrome führt Lesezeichen aus der Lesezeichenliste nicht aus: Tippe den Namen „D2 Deutsch“ in die Adressleiste und dann das darunter erscheinende Lesezeichen. Auf dem iPhone öffnest du auf der Startseite oder der Spielseite die Safari-Lesezeichen und tippst es dort an.

Prüfe außerdem, ob die ganze Adresse des Lesezeichens durch den Code ersetzt wurde und mit javascript: beginnt.

Das Spiel lädt auf dem Handy mitten im Spiel neu?

Meist ist dem Handy der Arbeitsspeicher ausgegangen und der Browser hat den Tab neu geladen. Das hilft:

  • Das Lesezeichen auf der Startseite d2survivors.lol benutzen und nicht zuerst die Spielseite öffnen – sonst lädt erst das Originalspiel und belegt weiter Speicher.
  • Im Spiel unter „Optionen → Grafikoptionen“ „Energiespar-Grafik“ einschalten.
  • Andere Tabs schließen.

Nach dem Neuladen einfach das Lesezeichen erneut benutzen; der Fortschritt entspricht dem Spielstand, den das Spiel selbst gespeichert hat.

Funktioniert es, wenn ich das Spiel zum Home-Bildschirm hinzufüge?

Nein. Vom Home-Bildschirm aus öffnet sich das Spiel im Vollbild, ohne Adressleiste und ohne Lesezeichen, und die Übersetzung bleibt nicht erhalten: Nach dem Neuladen oder erneuten Öffnen ist wieder das Original da. Spiel deshalb in einem Safari- oder Chrome-Tab und tippe nach jedem Öffnen oder Neuladen erneut auf das Lesezeichen.

Werden Läufe mit Übersetzung an die Bestenliste gesendet?

Im Browser ja. Mit dem Lesezeichen werden Läufe wie gewohnt an die Bestenliste gesendet, bei Normal wie bei Hardcore, und jeder Eintrag zeigt die tatsächlich benutzte Sprache (zum Beispiel de).

Am PC markiert das Spiel Einträge als patched, wenn du eine übersetzte Sprache wählst; für normale Einträge wähle im Launcher unter „Spielsprache“ English.

Windows meldet „Der Computer wurde durch Windows geschützt“. Was tun?

Der Launcher ist nicht signiert (ein Zertifikat kostet jedes Jahr Geld), daher warnt Windows SmartScreen, bis ihn genug Leute heruntergeladen haben.

Signiert ist er nicht, aber Quellcode und Build-Prozess des Launchers sind öffentlich.

Klicke auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“; danach fragt Windows nicht mehr. Lade ihn nur von dieser Website oder von GitHub Releases. Jedes Release enthält d2s-launcher.exe.sha256, prüfbar mit certutil -hashfile d2s-launcher.exe SHA256.

Meldet der Browser, dass die Datei selten heruntergeladen wird, wähle im Menü des Downloads „Beibehalten“.

Kann ich Umlaute im Charakternamen verwenden?

Leider nein. Das Spiel selbst erlaubt in Charakternamen nur englische Buchstaben (ohne ä, ö, ü, ß) und Koreanisch.
