維基›天梯規則

非官方翻譯。本頁翻譯自 D2 Survivors 官方 wiki 的〈Ladder rules〉，上次對照官方：2026-11-12。內容以官方原文為準。

天梯規則

天梯的排名依據、一局會送出什麼、怎樣才算數，以及不算數時該怎麼做。

排行榜

  • 天梯屬於恐懼階：每一階各有一個排行榜，依通關時間排名。普通、惡夢與地獄沒有排行榜。
  • 排行榜顯示每位玩家每個職業的最佳一局，最快的在前，最多100筆。時間相同時，等級較低的排在前面，其次是較早送達的一局。
  • 每個排行榜都可以顯示所有職業或單一職業，就像《暗黑破壞神 II》的天梯每個職業都有一個分頁。
  • 每一列顯示名次、名稱（沒有名稱時顯示職業）、職業、等級、英雄最高的6個技能、時間與日期。點擊即可開啟英雄當時的角色畫面：裝備、咒符欄、技能及其變體，以及傭兵。
  • 重玩已通關的階也算數，會標示「重玩已通關的階」。在99級重新開始的英雄會標示「已從等級99重新開始」。
  • 在營地中，排行榜位於架上的天梯之書裡，分頁為「恐懼」、「尋找」與「你」。在網站上則位於天梯頁面，另有各玩家的頁面與統計資料。
  • 非專家與專家級各有自己的排行榜。專家級的排行榜多一個「依等級」分頁，像《暗黑破壞神 II》的天梯一樣依等級為英雄排名；而且只有在天梯看過該英雄的每一局時，才會為英雄排名（專家級）。

一局會送出什麼

  • 恐懼階的首領倒下時，就會送出一局的紀錄：牛王、群魔亂舞關卡的超級首領，以及超級崔斯特姆最後倒下的三大罪惡之源也一樣。時間從該階開始計算到首領倒下為止。在專家級中，在某個難度擊敗巴爾也會送出紀錄，用於英雄的生涯紀錄與「依等級」，但不會出現在任何排行榜上。
  • 死亡或未完成的一局不會送出紀錄（專家級還會送出每一局的開始與結束：專家級）。不過在恐懼階中的死亡仍會記入英雄的攀升紀錄並送出，因此能辨識出還原到死亡之前的存檔。
  • 「你」分頁會說明送出哪些資料：「紀錄會上傳你的英雄的職業、等級、配置、裝備與屬性，以及你的名稱」。一局還會送出英雄的傭兵、另一組武器、咒符欄、技能變體、恰西的每一個強化階、存檔的金幣、這一局的擊殺數與傷害、遊戲的版本、平台與語言，以及自天梯上次儲存該存檔的一局以來，存檔找到或使用的每把鑰匙、每個器官、喬丹之石、滅絕與地獄火炬。「不會傳送其他任何資料，不含帳號，也不含位址。」
  • 英雄抵達恐懼階後，每一局也會附上英雄的攀升紀錄：自天梯上次全部計入以來通關的各階，以及各自的時間與日期。請見隱私權頁面。
  • 無法立即送出的一局會在裝置上等待，最多40局。每局最多等待30天，之後就會捨棄。超過40局時，會先捨棄被天梯拒絕的一局，再捨棄最舊的。新的一局一定會在重試被拒絕的一局之前送出。
  • 遊戲開啟期間，等待中的紀錄每次送出5局，最舊的先送，每次間隔20分鐘。
  • 「從頭開始」（選項、遊戲設定）會捨棄與該存檔一起等待的紀錄，被拒絕的也包括在內。專家級與非專家各自只捨棄自己的紀錄。
  • 在非專家中，若在「你」分頁關閉「上傳我的紀錄」，會顯示「你的通關紀錄只會保存在此裝置」：不會送出任何通關紀錄，已在等待的紀錄也會留在裝置上。重新開啟後，等待中的紀錄就會送出，而你的下一局會在攀升紀錄中附上這段期間通關的各階。
  • 在遊戲外修改過的存檔、網址中帶有改變玩法設定的頁面，或由自動化程式操作的瀏覽器，都絕不會送出紀錄。

怎樣的一局才算數

不論遊戲怎麼說，天梯都會以這些規則檢查每一局。違反任何一條的一局會被整筆拒絕，永遠不會儲存。遊戲會保留它，每6小時重送一次，總共8次，因此被規則誤拒的一局在規則修正後就能登錄。之後遊戲便會捨棄它。版本比其排行榜還舊的恐懼階紀錄永遠不會再算數，因此遊戲會立即捨棄。

  • 對英雄設下的每項上限，都是遊戲本身的上限，或遠高於任何真實英雄能達到的數值，因此合規的英雄絕不會因為數值而被拒絕。
  • 「你」分頁也會說明：「經過修改或使用模組的紀錄不予計算」。
  • 單純匯入不構成拒絕的理由：透過「存檔」移入的存檔與其他存檔一樣算數。
規則一局會被拒絕的情況
正式版本不是來自遊戲的正式版本，或來自一個在超過45天前已被較新正式版本取代的版本。/next/ 上的預覽版不算正式版本。
恐懼階紀錄的版本非專家或專家級的恐懼階紀錄，在比其版本更新的平衡性改版上線超過2小時後才結束（見下文）。版本早於 20261101.1 的非專家恐懼階紀錄，不論何時結束都會被拒絕：非專家的恐懼階排行榜從該版本起重新開始。
未經修改的遊戲在網址中帶有改變玩法設定的頁面、開發版本，或檔案被更改過的桌面版（模組）上遊玩。
正常的存檔存檔是透過匯入取得，其中有正常遊玩不可能得到的數值。
等級等級超出1-99，或經驗值超過該等級所需。
時間在30:00內通關一個難度（巴爾出現之前），在1:30內通關一個恐懼階（沒有波次的超級崔斯特姆不限時間），或恐懼階超過其10:00的時間限制。
屬性點數屬性點數比《暗黑破壞神 II》在該英雄等級加上三本藍伊森之書所給的還多，且超出寬限的20點；或屬性與英雄的點數及恰西的強化階對不上。
技能不屬於英雄職業的技能或被動技能、超過最高等級或超過英雄欄位數的技能、超過3次技能樹選擇、不屬於該技能的技能變體，或超過每個職業擁有的10點變體點數。
裝備英雄穿戴的、另一組武器中的、咒符欄中的或傭兵身上的物品，超出遊戲給予的數值範圍，或不是遊戲產生的物品。不可能雇到的傭兵。
恰西的熔爐英雄、另一組武器或傭兵穿戴的物品，帶有天梯的熔爐嘗試紀錄中沒有的淬鍊或升級：從未做過的、較舊的，或屬於其他物品的（恰西的熔爐）。
數值抗性超過95%（在恐懼階為98%，因為畫面會將97.5%的上限顯示為整數），或英雄角色畫面上的每秒傷害超過300,000,000。在恐懼階深處，這個上限會隨怪物的生命提高：第100階為1,516,322,058。英雄裝備上每有一次恰西熔爐的淬鍊，上限就提高五分之一。
攻擊傷害角色畫面的攻擊傷害超過 +100,000%，或遠超過英雄的裝備與咒符所給的數值。畫面加上但裝備上沒顯示的部分會納入考量：聖騎士的神聖靈氣最多40倍、德魯伊的烈焰爪擊最多40倍，英雄或傭兵裝備上的靈氣、附魔（鐵狼衛士的或英雄裝備的）或沙漠傭兵的神聖冰凍最多4倍。熔爐淬鍊會將 +100,000% 的上限提高其增加量的40倍。
魔寶尋獲率與金幣尋獲率角色畫面的魔寶尋獲率超過3,000%或金幣尋獲率超過 +6,000%，或任一項超過恰西的強化階與英雄的裝備和咒符所給數值的1.5倍。熔爐淬鍊會將兩個上限各提高其增加量的1.5倍。
恰西的強化階英雄向恰西購買的所有商品強化階，總花費超過到這一局結束時遊玩可能賺到的金幣兩倍；已超過恐懼第90階的存檔則容許更多。網站上一局的頁面會顯示魔寶尋獲率與金幣尋獲率的強化階。
速度在恐懼階每分鐘擊殺超過4,000，或在普通、惡夢、地獄超過12,000，或每秒傷害超過上述上限，且持續一分鐘以上。每分鐘擊殺從這一局開始擊殺時起算：恐懼階從該階開始時起算，絕不以英雄的總遊戲時間計算。或者，恐懼階的一局造成的傷害遠少於被擊殺怪物的生命總和：從1,000次擊殺起，第1階每次擊殺低於3,500傷害，此下限會隨各階怪物的生命提高。

通過驗證的恐懼階攀升

只有英雄一階一階攀升取得時，恐懼階才會計入其排行榜。前面沒有任何階數支撐的深層階不會列入排名。

  • 英雄的存檔會保存攀升紀錄：每個通關的階、首領倒下時的遊戲時間與日期，以及通關時間，每一步都與前一步相連。
  • 通關只會從下面一階，或從以快速通關解鎖該階的階延續紀錄（恐懼階）。英雄在各階中的死亡也會記在上面。
  • 紀錄無法支持其所在階的一局會被儲存，但列為未驗證。它會顯示在該階排行榜下方的「未驗證的紀錄」中，游標移上去會顯示「此階不列入排名」與原因。
  • 在專家級中，任何一局都可能不列入排名（專家級）。

平衡性改版

  • 平衡性改版是會讓英雄變弱的改版。上線後，在較舊版本上進行的恐懼階紀錄，只有在2小時內結束才算數。
  • 在那之前進行的一局，不論何時送出都算數。重要的是何時結束，而不是何時送達。
  • 在網站上，停留在較舊版本的頁面會在選單與營地中提示：「平衡性已調整：點擊以重新載入，否則你的恐懼局紀錄將不再計入」

你的 ID 與名稱

  • 你的存檔會在送出第一局時產生一個隨機的匿名玩家 ID。天梯只保存它的雜湊值。沒有帳號。
  • 網站上的玩家頁面會依雜湊值列出以該 ID 送出的紀錄，包含非專家與專家級。
  • 可在網站排行榜上方的方框中依名稱尋找玩家，會找到非專家與專家級的玩家；或在營地天梯之書的「尋找」分頁尋找，會找到該營地的玩家。輸入名稱任一部分的2個以上字母，不分大小寫。最多列出20位玩家：名稱完全相同的優先，其次是以此開頭的名稱，然後是其餘的，各依送出的紀錄數排序。
  • 點選找到的玩家會開啟該玩家的紀錄：在網站上是玩家頁面，在書中則是由新到舊的紀錄，點選每筆紀錄可開啟該英雄。玩家是依最近一筆帶有名稱的紀錄上的名稱來尋找。
  • 名稱可有可無，在「你」分頁中設定。沒有名稱時，你的紀錄列會顯示你的職業。
  • 名稱遵循《暗黑破壞神 II》的角色名稱規則：2到15個字母，也可以用韓文，中間最多一個 - 或 _，且不能在頭尾。少數歧視字眼會被拒絕。
  • 被天梯拒絕的是名稱，絕不是這一局：該列會改為顯示職業。
  • 專家級的存檔在建立時會沿用非專家的 ID 與名稱，在其中一邊改名，兩邊都會改。非專家的存檔代碼可將它們帶到另一台裝置。

紀錄不算數時

  • 「你」分頁會顯示「你的紀錄有效」，或「你的紀錄無效」並附上原因，游標移上去還會說明如何修正。紀錄無效期間，角色畫面會以紅字顯示「此英雄的紀錄不會列入排名」。
  • 正常遊玩不可能得到的物品會有紅色邊框，資訊框中還有一行紅字說明原因。把它卸下或從咒符欄中拿出，英雄的紀錄就會再度算數。
  • 屬性點數或技能點數過多：阿卡拉的重新抽選或赦免徽章，會退回該等級合規英雄應有的點數。英雄持有的屬性點數多於遊玩所能取得時，阿卡拉的重新抽選免費。
  • 在非專家中，被標示為已修改的存檔，只要沒有任何英雄的配置與穿戴的物品違反規則，就會再度合規。遊戲會在重新抽選後以及每次穿戴的裝備變動時檢查，從那之後就會送出它的紀錄。
  • 儲物箱與物品欄中的物品仍保有紅色邊框，但不會造成任何影響。
  • 未驗證的恐懼階紀錄會一直維持未驗證。你的攀升會從紀錄中最深的階繼續。天梯無法計入的階會留在紀錄上並隨每一局送出，因此一旦它算數，其後的各階也會算數。
  • 專家級英雄的標記是永久的：新英雄會從乾淨的狀態開始（專家級）。
  • 若要刪除一局或你所有的紀錄，請寄信到隱私權頁面上的地址，附上其中一局的連結或你在天梯上的名稱。
