維基›專家級

非官方翻譯。本頁翻譯自 D2 Survivors 官方 wiki 的〈Hardcore〉，上次對照官方：2026-11-11。內容以官方原文為準。

專家級

每位英雄只有一條命：其存檔與營地、墓園、死亡會失去什麼，以及天梯上的排行榜。

每位英雄只有一條命

  • 在專家級中，英雄只有一條命，與《暗黑破壞神 II》的專家級相同：英雄的生命第一次降到0時，就會永久死亡。
  • 在專家級中，恰西不出售「復活」。該列會顯示「專家級中不販售」。
  • 死亡會在畫面顯示任何東西之前就記錄下來。在倒下的過程中關閉分頁或程式，英雄也不會留下任何東西。
  • 死亡畫面只提供「主選單」，並以《暗黑破壞神 II》的「你的英勇長存人心」取代死亡造成的損失說明。
  • 一局中途使用「儲存並離開」、關閉分頁或當機都不算死亡：英雄仍然活著，「繼續」會從該章開頭重新開始（存檔）。
  • 恐懼階時間耗盡會結束這一局，但不會殺死英雄。損失與在該階非專家死亡相同（恐懼階）。

專屬的存檔與營地

  • 專家級是與非專家並存的獨立存檔，有自己的英雄、金幣、儲物箱與強化。兩者之間不互通任何東西（存檔）。
  • 建立專家級存檔時，只會從非專家存檔複製兩樣東西：你的天梯 ID 與名稱，以及你的「拾取篩選器」。
  • 網址中帶有改變遊戲玩法設定的頁面，或由自動化程式操作的瀏覽器，都無法開始專家級的一局。傳送平台會顯示「無法在測試頁面開始專家級的一局」。
  • 營地營火旁的黑暗流浪者會帶你往返兩個營地。第一次前往專家級時他會先警告你；在未加入主畫面的 Safari 中則每次都會警告（營地）。
  • 專家級的營地是夜晚，播放崔斯特姆的音樂。「俠盜營地」下方會以紅字顯示「專家級」，營火周圍英雄的名字也是紅色（營地）。
  • 職業擊敗巴爾時，會獲得《暗黑破壞神 II》的專家級頭銜，而非非專家的頭銜。
  • 專家級存檔無法匯出或匯入，而且專家級需要能保留存檔的瀏覽器（存檔）。
擊敗巴爾的難度非專家頭銜專家級頭銜

墓園

  • 最近倒下的12位英雄會以墳墓的形式立在營地南角的墓園中，最新的排在最前面。游標移到墳墓上會顯示等級與職業、英雄倒下的地點、被什麼殺死，以及日期。
  • 因「從頭開始」而被埋葬的英雄，墳墓上會寫著「因『從頭開始』而安息」。
  • 遊戲也會在存檔之外保存墳墓。把死亡前的存檔複製回來也無法讓死者復活：存檔載入時英雄就會再次死亡。
  • 天梯也知道誰已經死去。天梯記錄為死亡的英雄若在存檔中還活著，下次你回到營地時就會被埋進墓園，不論存檔來自何處。

死亡會失去與保留什麼

  • 專家級的死亡會帶走英雄：等級、經驗值、配置、存下的英雄與存檔的一局、金色光芒，以及最高恐懼階。
  • 英雄穿戴與攜帶的一切、兩組武器與咒符欄也會失去。從儲物箱拿在手上的物品會回到儲物箱。從英雄自己的裝備拿在手上的物品則會與英雄一同消失。
  • 英雄在普通之後開放的難度、擊殺巴爾的紀錄與頭銜、恐懼階、阿卡拉的免費重置，以及這一局尚未存下的金幣也會失去。
  • 在英雄身旁作戰的傭兵會失去他的裝備。他會等待該職業的下一位英雄。
  • 存檔會保留存下的金幣、恰西的強化與灌注魔力、所有儲物箱分頁、鑰匙與器官（超級首領）、迪卡‧凱恩的獲救與任務、技能變體、已雇用的傭兵，以及「拾取篩選器」。
  • 在天梯的物品檢查中，存檔仍會計入倒下的英雄所到達的最深恐懼階，因此其他英雄穿戴在那裡找到的裝備進行的一局仍會通過驗證（天梯規則）。
  • 英雄攜帶但尚未閱讀的凱恩獎勵會回到他手上，留給該職業的下一位英雄。
  • 該職業的下一位英雄會從普通難度的等級1開始。
  • 在專家級中，阿卡拉的從頭開始會讓英雄永久退休，並由新的英雄從等級1開始。專家級無法換回英雄。
  • 在專家級中使用「從頭開始」（選項、遊戲設定）時，會先把每位活著的英雄當作死亡埋葬，然後只清除專家級的存檔。

天梯上的專家級

  • 專家級有自己的排行榜，每個恐懼階各一個，完成時間、規則與檢查都與非專家相同（天梯規則）。非專家的一局不會登上這些排行榜，專家級的一局也不會登上非專家的。完成普通、惡夢或地獄不會登上任何排行榜，但仍會計入英雄的生涯紀錄與依等級的天梯。
  • 在專家級的營地中，天梯之書會開在專家級的排行榜，排行榜名稱旁以紅字顯示「專家級」，並多一個「依等級」分頁。其「尋找」分頁可依名稱尋找專家級的玩家。
  • 「依等級」就是《暗黑破壞神 II》的 Battle.net 天梯：所有列入排名的英雄依等級與經驗值排序，再依專家級排行榜上通過驗證的最深恐懼階排序，活著與死去的英雄並列。
  • 死去的英雄以紅字顯示，並附上倒下的日期，游標移到該列上會顯示倒下的地點與被什麼殺死。篩選器可只顯示活著的英雄。
  • 等級超過天梯記錄到的章節所能給予的等級時，會標上「可能異常」：「等級高於排行榜記錄到的各局所能達到的等級」。英雄仍列入排名，等記錄到的章節追上後標記就會消失。
  • 點擊一列會在角色畫面中開啟該英雄最近一次完成的恐懼階，並以紅字標示「專家級」。網站的天梯頁面也有非專家與專家級的切換，以及「依等級」分頁。

完整被記錄才列入排名

天梯無法保管你的存檔，但能看到專家級英雄每一局的開始與結束。只有在每一局都看到時，它才會讓英雄列入排名。

  • 每一局開始時會報到，每章開始時會記錄，結束時會送出結果：完成、「儲存並離開」、恐懼階時間耗盡或死亡。存檔會把這些步驟保存為英雄的生涯紀錄，每一步都與前一步相連。
  • 每次連線會送出英雄的金鑰（由建立英雄時產生的隨機 ID 製成）、這一局專屬的隨機票證、各章節與其時間、英雄的職業、等級與經驗值、遊戲版本，以及你的玩家 ID 與名稱。死亡時還會送出英雄倒下的地點與被什麼殺死。請見隱私權頁面。
  • 一局絕不會等待天梯的回應。連線一次送出一個，每個都在前一個收到回應或過了15秒後才送出。沒有收到回應的報到、章節或離開紀錄會留在存檔中，依序重新送出，直到天梯回應為止，最長30天，因此離線進行的一局也會在遊戲連上天梯後送達。完成紀錄會排在它們之後。天梯始終沒有收到的報到會讓英雄永久不列入排名，除非是天梯本身停擺。
  • 以下情況絕不會對英雄不利：當機、重新載入或關閉分頁（下一局的報到會帶上離開紀錄）、重複送出的連線、緩慢或中斷的連線（連線會重新送出）、裝置時鐘設定錯誤，或在天梯本身停擺（例如維護）時送出的報到。
  • 英雄一旦不再列入排名，就是永久的，除非天梯自己撤回標記，就像它曾為自身停機所做的那樣：遊戲會在英雄的下一局移除標記。之後建立的英雄則不受影響。
顯示的原因意思
有一局開始時未連上排行榜某一局的報到始終沒有送達天梯：「上傳我的紀錄」已關閉，或遊戲在30天沒有回應後放棄重送。
以較舊的存檔副本遊玩英雄的紀錄與天梯保存的不同：把舊存檔複製回來，或在同一局中同一章開始了兩次。
此英雄的存檔曾在遊戲外被修改英雄的紀錄前後無法銜接，或存檔在遊戲外被修改過。
在此英雄死亡後仍被遊玩天梯記錄該英雄已死亡。之後的各局會另外保存。

未列入排名的英雄與「上傳我的紀錄」

  • 「上傳我的紀錄」關閉時，專家級的一局不會送出任何資料，因此這時遊玩的英雄將永遠不會再列入排名。天梯之書的「你」分頁會以紅字提示：「現在遊玩的專家級英雄將不會再列入排名」。
  • 「上傳我的紀錄」關閉時，在傳送平台以已列入排名的英雄開始需要再點擊一次（「此英雄將不會再列入排名。請再點擊一次」），並說明原因：「『上傳我的紀錄』已關閉。現在遊玩的話，你的魔法使將不會再列入排名。」
  • 訓練場不算一局：不需要再點擊一次，也不會向天梯送出任何資料（營地）。
  • 若天梯已3分鐘沒有回應，傳送平台開啟時會再次詢問天梯。
  • 未列入排名的英雄仍可遊玩並送出每一局。這些紀錄會保存在每個專家級排行榜的「未列入排名的紀錄」下，游標移上去會顯示「不列入排名」與原因；該英雄也會連同原因列在「依等級」分頁的「未列入排名的英雄」下。
  • 位於被複製回來覆蓋較新存檔、或在遊戲外被修改過的專家級存檔中的英雄，可以繼續遊玩，但永遠不會再列入排名（存檔）。
  • 其他一切都遵循非專家的規則：一局必須合規，恐懼階的攀升也必須通過驗證（天梯規則）。
