維基›新手入門

非官方翻譯。本頁翻譯自 D2 Survivors 官方 wiki 的〈Getting started〉，上次對照官方：2026-11-10。內容以官方原文為準。

新手入門

遊戲與遊玩循環、需要準備什麼、操作方式與畫面。

遊戲介紹

  • D2 Survivors 是以《暗黑破壞神 II》的美術、音效與規則打造的倖存者類遊戲。怪物從四面八方湧來，你要不停移動，讓技能替你戰鬥。
  • 你將扮演《暗黑破壞神 II》7個職業的其中之一。每個職業都有專屬的技能、被動技能與裝備，且各有一位英雄。
  • 技能會自動施放，各有各的冷卻時間。你從不需要瞄準或按技能鍵：只要移動就好。
  • 一局共有五章，每章6分鐘，依序穿越《暗黑破壞神 II》的各個區域。每章最後都有首領：安達莉爾、都瑞爾、墨菲斯托、迪亞布羅、巴爾。
  • 畫面下方的精力條會隨著這一章的進行逐漸減少。精力條耗盡時，章節首領就會出現。擊敗他之後，他的紅色傳送門會帶你前往下一章。
  • 每次擊殺都會留下經驗寶石。每升一級，這一局就會暫停並出現3張卡片：新的技能或被動技能，或是已擁有的技能或被動技能再升一級。從中選一張。
  • 章節首領與部分精英會掉落寶箱。寶箱會給予更多次升級，或讓已就緒的技能進化，另外還有金幣。
  • 怪物會掉落《暗黑破壞神 II》的裝備與金幣。撿到的裝備立刻歸你所有。金幣則會在這一局結束時存起來。
  • 死亡會結束這一局。擊敗巴爾會為該職業開放惡夢難度：你可以在同一局中繼續進入惡夢，也可以就此結束這一局。惡夢的巴爾會開放地獄，地獄的巴爾則會開放恐懼階。
  • 一局如何逐章進行：一局的流程。哪些東西會從一局保留到下一局：存檔。

每局之間的營地

  • 主選單有「進行遊戲」、「選項」、「存檔」與「離開」。右上角的「新聞」會列出每個版本的變更。有新內容時，它的寶石會發出金光。
  • 「進行遊戲」會以你上次使用的英雄進入俠盜營地。每一局結束後都會回到那裡。
  • 傳送平台是進入一局的唯一途徑。各種起點會列在其起始的章節底下：第一章底下有普通、惡夢與地獄，你存檔的一局顯示為「繼續」，恐懼階開放後也會列在這裡。
  • 其他職業的英雄站在營火旁。點擊其中一位即可改用該英雄遊玩。
  • 恰西會用你存下的金幣出售裝備與她的強化，也會收購你要賣的東西。在她的熔爐，她會為你的物品淬鍊、清除與升級（恰西的熔爐）。基德提供賭博。阿卡拉出售藥水與施法者武器，也能重置你的英雄或讓英雄從頭開始。卡夏雇用傭兵。救出迪卡‧凱恩後，他會發放任務獎勵。點擊儲物箱即可開啟。
  • 營火旁的黑暗流浪者可切換你的非專家與專家級存檔：見存檔。
  • 在桌面版中，「離開」會先詢問再關閉程式。在網站上則會回到標題畫面。
  • 如果你的檔案中沒有《暗黑破壞神 II》的選單美術，會改用簡易的職業選擇畫面：只有普通難度，沒有營地，也沒有「選項」。

需要準備的東西

  • 遊戲本身不含任何暴雪的檔案。它使用你自己的《暗黑破壞神 II》與毀滅之王（1.14），或《暗黑破壞神 II：獄火重生》，在你的電腦上讀取一次後即可遊玩。不會上傳任何東西。
  • 經典版安裝需要 d2data.mpq、d2char.mpq、d2sfx.mpq、d2exp.mpq、patch_d2.mpq。音樂與語音可有可無：d2music.mpq、d2xmusic.mpq、d2speech.mpq、d2xtalk.mpq。
  • 從 Battle.net 或 Steam 安裝的《暗黑破壞神 II：獄火重生》也可以。音效與音樂會是 D2R 本身的版本。
  • 在網站上，設定頁面會在瀏覽器中讀取你的安裝：選擇安裝資料夾，再按「擷取」。安裝也可以位在你所選資料夾的裡面，例如 Steam 收藏庫。資料夾選錯時，設定頁面會指出缺少什麼。
  • 支援桌機版的 Chrome、Edge、Firefox 與 Safari，會在瀏覽器中保存約1.1 GB的資料，並要求瀏覽器永久保留這些資料。
  • 新版本若以不同方式讀取部分檔案，遊戲會帶你到設定頁面，只重新擷取那些檔案。Chrome 與 Edge 會記住資料夾。Firefox 與 Safari 則要你重新選擇，頁面會告訴你是哪個資料夾。
  • 在一局之外，「選項」、「遊戲設定」、「遊戲檔案」可再次開啟設定頁面：用來重新擷取，或從瀏覽器移除檔案。
  • 網站仍提供時，設定頁面也有「網站提供的檔案」可選：遊戲會在你遊玩時從網站下載美術與音效。設定頁面會提醒這些檔案即將停止提供。之後，網站就只能使用你自己的檔案遊玩。
  • 手機或平板無法讀取安裝，因此在網站仍提供時，會使用網站提供的檔案遊玩。之後，沒有你自己檔案的瀏覽器（手機也一樣）只會看到一個頁面，說明網站提供檔案的版本已經結束，無法遊玩：頁面上有使用你自己檔案或桌面版的方法，也可以下載你的非專家存檔。
  • 不論有沒有遊戲檔案，你的英雄都會保存在瀏覽器中。在你自己的檔案與網站提供的檔案之間切換，不會改變存檔中的任何內容。
  • 在網站上，網站推出新版本後，選單與營地會顯示「新版本已就緒：點擊以重新載入」。一局進行中絕不會顯示。

桌面版

  • 桌面版不需要瀏覽器，可離線使用你的安裝遊玩。支援搭載 Apple Silicon 的 Mac、Windows 與 Linux（包括 Steam Deck）。Linux 版為測試版。
  • 第一次啟動時，它會在常見位置尋找《暗黑破壞神 II》或 D2R，或請你指定位置，然後擷取一次。它會先確認磁碟空間是否足夠，並告訴你需要多少。若選到《暗黑破壞神 III》或《暗黑破壞神 IV》的資料夾、Battle.net 仍在更新中的 D2R、無法讀取的磁碟機，或是複製一開始就被中止（多半是防毒軟體所致），它都會指出問題並說明該怎麼做。
  • 擷取若中途停止（例如在記憶體不足的電腦上），會從剩下的步驟重新開始一次，一次只做一個步驟。
  • 更新後若部分檔案的讀取方式改變，它會自動只重新擷取那些檔案。選單中的「重新擷取遊戲檔案…」會重新擷取全部檔案。
  • 它會自動更新。新版本會在背景下載，選單角落會顯示「更新已就緒：點擊以重新啟動」。「選項」、「遊戲設定」、「自動更新」可關閉更新檢查。
  • 第一次執行安裝程式時，因為沒有數位簽章，Windows 會發出警告：請選擇「其他資訊」，再選「仍要執行」。
  • 全螢幕在 Mac 上是 Ctrl+Cmd+F，在 Windows 與 Linux 上是 F11，也可以使用「選項」中「顯示設定」的「全螢幕」。下次開啟時，程式會維持你離開時的狀態。
  • 它的存檔存在你的磁碟上，與所有瀏覽器分開。可用「存檔」轉移：見存檔。

鍵盤與滑鼠

  • 點擊某個位置即可走過去，或按住滑鼠左鍵用游標控制方向。方向鍵也能行走，而且會優先於滑鼠。
  • 「選項」的「鍵盤」會列出下方所有按鍵，並可重新設定：選擇一個按鍵，按 Enter，再按下新的按鍵。每個動作可設定一個按鍵與一個第二按鍵，按 Delete 可移除其中一個。若設定的按鍵原本屬於其他動作，會從該動作移除，該動作會以紅色顯示，直到重新設定按鍵為止。「使用WASD移動」會讓 W、A、S、D 與方向鍵一樣能行走，並把武器切換改到 E。「恢復預設值」會把所有按鍵恢復原狀。Esc 永遠不會改變。按鍵設定保存在這個瀏覽器中，所有提示都會顯示你設定的按鍵。在一局中第一次按 W、A、S 或 D 卻沒有移動，或按 W 切換了武器時，會出現一行說明行走改到哪裡，在這個瀏覽器只會顯示一次。
  • 點擊英雄無法到達的位置（例如樹、巨石或牆的另一側）時，英雄一旦無法再靠近就會停下。
  • 在配置列或技能樹旁的技能欄位上按右鍵，即可暫停該技能。暫停中的技能會停止施放，直到你再按一次右鍵。存檔的一局會保留暫停狀態。被動技能無法暫停。裝備自動施放的技能也能用同樣方式暫停，並會在每一局中保持暫停，直到你重新啟用。
  • 升級時，按 1-3 選擇卡片，R 重抽，X 跳過，B 排除。最初1.2秒卡片會淡入，不接受任何輸入：點擊、輕觸或手把按鍵要在這之後才開始才算數，鍵盤按鍵也要在這之後才按下才算數，因為一局中你隨時都在點擊、輕觸與喝藥水。
  • 升級卡片關閉後的0.5秒內，腰帶按鍵不會喝藥水，因此連按兩次卡片的按鍵不會喝掉藥水。
  • 滑鼠的上一頁與下一頁按鍵在遊戲中沒有作用。
  • 在網站上，一局進行中按「上一頁」、Ctrl+W 或 F5 時，瀏覽器會先詢問：這一局會存檔，但「繼續」會從該章開頭重新開始。iPhone 或 iPad 的瀏覽器不會詢問。

手把

  • 手把可以玩整個遊戲：在 Chrome、Edge、Firefox、Safari 與桌面版中，支援 Xbox、PlayStation 與 Switch Pro 手把。手把與鍵盤中最後使用的那一個會控制畫面。其他視窗在前景時，手把不會操作任何東西，因此你可以開著桌面版，用手把玩其他遊戲。
  • 瀏覽器沒有標準配置的裝置（D-input 模式的手把、飛行方向舵、方向盤的踏板）要先按下一個按鈕才會啟用。之後搖桿要離開原本停放的位置才會控制方向，因此停在一端的油門桿不會讓你走動。
  • 左搖桿控制行走，只推一部分時走得較慢。技能仍會自動施放。
  • 在選單中，用十字鍵或搖桿移動，下方的按鈕確認，右方的按鈕或 Start 返回。
  • 在其他畫面（升級卡片、恰西的介面、角色畫面、傳送平台、任務記錄、「存檔」）中，金色框會在可點擊的項目之間移動，按下方的按鈕即可按下。升級時，X（□ 鍵、Y）重抽，Y（△ 鍵、X）跳過，RB（R1、R）排除。
  • 在物品欄與儲物箱中，A（× 鍵、B）拿起與放下，X（□ 鍵、Y）裝備，Y（△ 鍵、X）出售或存入儲物箱。Y（△ 鍵、X）對已穿戴的裝備或咒符無效，畫面剛開啟時也無效。按住 LB（L1、L）可比較，與 Shift 相同。
  • 使用手把時，畫面上的提示會顯示手把的按鈕名稱。
  • 受到攻擊與章節首領死亡時，手把會震動（瀏覽器支援時）。
  • 「選項」的「控制器」：「震動」開關、「搖桿死區」從5%到50%（預設20%）、重新設定下方各動作的按鈕，以及「恢復預設值」。把某個按鈕指定給一個動作時，會從原本使用它的動作取走，該動作則改用舊的按鈕。
  • 控制器的設定保存在這個瀏覽器中。

手機或平板

  • 在任意位置拖曳，即可用跟隨拇指的虛擬搖桿控制方向，或輕觸某個位置走過去。
  • 「暫停」、「自動地圖」、「任務」與「角色」按鈕可取代 Esc、Tab、Q 與 C。
  • 輕觸這一局的計時器可切換每秒傷害顯示，與 L 相同。
  • 傭兵面板從他的頭像開啟：第一次輕觸顯示他的資訊框，第二次輕觸開啟面板。
  • 在角色畫面中，輕觸可拿起與放下物品，拖曳可把物品移到手指離開的位置，長按可裝備或卸下。手上拿著物品時，按「出售」可將其賣出；直拿手機的一局中，按「丟下」可放在腳邊。直拿且儲物箱開啟時，按「儲物箱」或「物品欄」按鈕可一鍵移到另一邊。
  • 輕觸腰帶欄位即可喝下藥水。手指一碰到就會喝，因此另一隻手指可同時控制方向。
  • 輕觸紅色傳送門即可走進去，或在傳送門中靜止片刻。
  • 武器組 II 有裝備後，會出現 I / II 按鈕，可切換到另一組武器，與 W 相同。
  • 長按技能欄位可暫停該技能，或重新啟用。
  • 在手機上，「顯示設定」的「顯示物品」會一直顯示地上所有物品的名稱，就像按住 Alt 時一樣。
  • 手機可直拿或橫拿遊玩。直拿時，《暗黑破壞神 II》的畫面會轉向側邊，選單、HUD 與營地也會改用直式版面。
  • 在 iPhone 或 iPad 上，即使響鈴／靜音開關切到靜音，音效與音樂仍會播放，就像影片一樣。一局中被手機停掉的聲音，會在你下次輕觸、按鍵或按控制器按鈕時恢復。
  • 將頁面加入主畫面，即可全螢幕遊玩。

一局中的畫面

《暗黑破壞神 II》的控制面板位於畫面底部。這一局的資訊列位於右上角。

  • 左下角的生命球顯示你的生命。中了怪物的毒時會變成綠色。
  • 生命球上方會為怪物施加在你身上的每種減益效果顯示一個小圖示，持續最久的排在最前，並附上剩餘秒數。將游標移到圖示上或輕觸，即可查看效果。
  • 與《暗黑破壞神 II》不同，技能從不消耗法力：右下角的法力球會一直保持全滿。來自物品、竊取與擊殺的法力改為提升施法速度，法力球的資訊框會顯示施法速度提升了多少。
  • 生命球與法力球旁的技能按鈕會顯示你的第一個技能（左）與最新的技能（右），冷卻中時會變暗。點擊任一個即可開啟技能樹。
  • 經驗條會朝下一個等級填滿。它的資訊框會顯示數值。
  • 精力條會隨著這一章的進行逐漸減少，接近耗盡時變成紅色。耗盡時章節首領就會出現。擊倒他之後，會倒數計時，直到他的傳送門帶你前進。
  • 兩者之間的腰帶分成4欄存放你的藥水。
  • 有屬性點數可分配時，控制面板上會顯示「新屬性點數」，按下可開啟角色畫面。
  • 中間的箭頭會開啟《暗黑破壞神 II》的迷你面板：角色、物品欄、技能樹、隊伍（你的傭兵）、自動地圖、任務記錄與遊戲選單。
  • 配置列分兩列顯示你的技能欄位與被動欄位，空的欄位也會顯示。下方以藍框顯示的一列是裝備自動施放的技能，有在施放時才會出現（物品）。
  • 這一局的資訊列：金色的區域名稱、章節與難度或恐懼階、擊殺數、恐懼階的波次、剩餘「復活」次數（有向恰西購買時）、藍色的恐懼階詞綴，以及找到的金幣。
  • 其下方是每秒傷害（若有開啟）。「簡易」為一列，顯示最近5秒的傷害。「詳細」會再加上傷害最高的5個來源及各自的佔比。可按 L、使用「顯示設定」的「顯示傷害」、按下手把的右搖桿或輕觸計時器切換。不論設定為何，訓練場都會完整顯示（營地）。
  • 上方的計時器顯示這一局的時間。
  • 上方中央的血條會顯示游標下的精英名稱，沒有則顯示章節首領，再沒有則顯示你正在交戰的精英，並附上其生命、種類、強化屬性與免疫。一般怪物不會顯示。
  • 訊息（精英出現、找到裝備、寶箱的戰利品）會在英雄頭上堆成一欄，最新的在最下方。
  • Tab 可循環切換自動地圖：覆蓋地圖、角落地圖、關閉。只會畫出你看過的地方。地圖會標示聖壇、紅色傳送門、寶箱、稀有、套裝、獨特與符文之語裝備、咒符、珠寶、精華（小的紅色三角形）、精英、首領與寶藏竊賊。下一局會沿用目前的模式。
