    • 在线游戏的一局如果使用了堆叠中的拉苏克精华后又捡起另一个，不再被拒绝
    • 在线游戏的一局开始前在营地点击某人，不再导致正当的游戏局被拒绝
    • 选择取代你某个技能的技能卡后，下一局在线游戏不再被拒绝
    • 在线游戏的一局如果在铁匠处赌博后，在购买完成前离开铁匠窗口再回来，不再被拒绝
    • 在线游戏的一局如果在角色界面将光标移到装备上，再从带有光环的武器切换走，不再被拒绝

  3. 2026-11-21 游戏更新 已支持桌面版游戏 2026.1120.1，新增的字符串均已翻译
    游戏本身的更新（游戏版本 2026.1120.1）

    • 网站排行榜的每局页面现在会列出英雄向恰西购买的每一阶强化
    • 任务日志的“六次进化”会显示你当前的配置持有六种进化中的几种
    • 自动地图会以紫色星号标示尚未收藏的暗金物品或套装物品
    • 自动地图会标示拾取过滤器中设为“保留”的行所指定的装备
    • 地上的超级钥匙与器官现在会像赫拉迪姆法典一样，在自动地图上以红色菱形标示
    • 使用手柄游玩时会隐藏鼠标指针，移动鼠标后会立即重新出现

    • 恐惧阶中，第三幕与第四幕的首领会多掉落一个燃烧的恐惧精华，因为这两幕没有超级钥匙

    • “选项”新增“控制器”设置，可关闭手柄，你在其他程序中使用的手柄就不会在这里产生作用
    • 基德的赌博现在会向亚马逊提供箭矢与弩矢，按赌博的几率成为魔法或稀有箭袋
    • 恰西的熔炉每次淬火现在会将一行属性提升其原始数值的40%（原为20%），已淬火过的物品也适用
    • 地狱熔炉的失败几率由60%降为30%，其余70%会让所有淬火翻倍
    • 一局进行中即使没有操作，屏幕也不再自动关闭
    • 火系精通、冰系精通与雷系精通在等级5时分别提供 +8% 火焰、+8% 冰霜与 +14% 闪电伤害，并仍会降低敌人抗性
    • 猎法者的陷阱与充能释放会随武器伤害成长，因此淬火武器也会提升它们
    • 猎法者的陷阱也会像充能释放一样，随力量、敏捷与物理伤害加成成长
    • 与《暗黑破坏神 II》相同，影身战士与影身大师会使用你的充能技能、双龙爪、飞龙在天与利刃之怒作战

    • 幕的传送门开启时，地上的装备与宝箱会飞到英雄周围的地面，让你拾取
    • 恰西现在收购英雄身上穿戴的物品前会先确认，物品栏中的物品仍可轻点一次就出售
    • “游戏设定”中的“吸取战利品”可以关闭，幕中的装备与宝箱会留在掉落处，不再飞向英雄
    • 恰西铁砧的“撤销”需要再按一次确认，误点不会再浪费淬火
    • 第100阶以后的恐惧阶会出现更多怪物，到第700阶时为1.5倍

安装

不需要手动修改任何游戏文件，全部交给启动器处理。请先关闭游戏。启动器的界面会使用你选择的语言。

  1. 先装好 D2 Survivors

    从 D2 Survivors 官网下载桌面版，按游戏的设置界面指定《暗黑破坏神 II》的安装位置，确认能正常进入游戏。

  2. 下载启动器

    下载 d2s-launcher.exe，放在任意文件夹即可，无需安装。

  3. 选择语言

    第一次打开会先出现语言界面，每种语言都用它自己的文字显示。点击你的语言、再点「→」，启动器的界面和游戏的翻译都会使用这个语言。

  4. 按设置向导完成三步

    ①「游戏」：找到 D2 Survivors（默认在 %LOCALAPPDATA%\Programs\D2 Survivors，装在别处就点「选择文件夹…」）。②「Diablo II」：查找你电脑上的《暗黑破坏神 II：狱火重生》或经典版，找不到也可以点「跳过」。③「完成」：可以点「在桌面创建快捷方式」，再点「启动游戏」。第一次会下载翻译，并自动备份原版 app.asar。

  5. 之后从快捷方式或启动器启动游戏

    默认每次启动都会获取最新的翻译（「设置」中的「启动时自动更新翻译」），游戏更新后也会自动重新应用。想换语言，在主界面的「游戏语言」中切换即可。

还原原版

  • 在启动器的「设置」中点「还原原版游戏」，游戏的 app.asar 就会换回原始文件。
  • 想暂时玩英文或韩文版，在「游戏语言」中选择 English 或 한국어 (원본) 再启动，就是没有修改过的原版。
  • 完全卸载：先还原原版，再删除启动器、桌面快捷方式和 %LOCALAPPDATA%\D2SurvivorsLauncher 文件夹。

桌面快捷方式

想自己创建快捷方式的话，把下面这行设为快捷方式的目标，双击即可直接用指定语言启动游戏，不会弹出启动器窗口。（启动器的「在桌面创建快捷方式」会打开窗口并直接启动游戏。）

d2s-launcher.exe --launch --lang zh-CN
--launch
应用语言并启动游戏
--play
打开启动器窗口并直接启动游戏（桌面快捷方式用的）

--no-update
本次不检查翻译更新
--update
只更新翻译
--restore
还原原版
--self-update

--status
显示当前语言、游戏版本和翻译状态

常见问题

这是官方翻译吗？

不是。这是玩家自制的非官方翻译，与 D2 Survivors 开发者及暴雪娱乐均无关。

这是开源的吗？

程序部分是。启动器、网站和工具的源代码都在 GitHub 上，采用 MIT 许可。启动器由 GitHub Actions 从公开的源代码自动编译（编译记录），每个 Release 都附有 d2s-launcher.exe.sha256，可以自行核对。

翻译数据（词典）目前没有开放许可，保留所有权利，详见 dict/LICENSE。词典中沿用的官方译名归 Blizzard Entertainment 所有。

有简体中文版吗？

有，已正式推出。用语以《暗黑破坏神 II：狱火重生》官方简体中文为准，按大陆的说法翻译，不是从繁体中文直接转换。在启动器的语言界面选择「简体中文」即可，也可以在游戏的语言设置里切换。

可以在 Mac、Linux 或手机上玩吗？

目前不行。启动器只有 Windows 版；官方的网页版已经移除，网页书签也随之停止，所以 Mac、Linux 和手机暂时无法使用这个汉化。

会影响我的存档吗？

不会。启动器只替换游戏文件夹中的 resources\app.asar，存档保存在其他位置，不会被读取或修改。替换前会先备份原版。

以前在网页版玩的存档能转到桌面版吗？

可以。官方保留了一个网页版存档转移页面（只有英文和韩文），会从浏览器里找出网页版的存档，让你下载为 .txt 文件。

一定要用当初玩网页版的同一个浏览器（同一个用户配置）打开这个页面，才能找到存档；换其他浏览器或用无痕窗口都找不到。

下载后打开桌面版，在主菜单选「存档」（SAVES）→「打开存档文件」（Open a save file），选择刚下载的 .txt 即可导入。专家模式（Hardcore）的存档和游戏里一样无法转移。

游戏更新后怎么办？

游戏更新会替换 app.asar，翻译会暂时消失。照常从启动器或快捷方式打开游戏就会重新应用。

如果新版本改动太大、修改规则无法匹配，启动器不会强行修改文件，而是先用原版启动游戏，并显示「游戏刚更新，翻译修正中」。翻译修好后，下次启动就会自动重新应用，什么都不用做。

为什么游戏语言菜单里的韩语变成了中文？

翻译借用了游戏内置的韩语语言位置，所以应用翻译后，菜单里的韩语会显示为所选语言的名称（例如「简体中文」）。想玩韩语版，在启动器中选择「한국어 (원본)」再启动。

为什么还有一些英文？

游戏里的文字都已翻译，也在游戏里检查过没有漏译。如果看到英文，通常是游戏刚更新、加入了新的文字；翻译会在之后的更新中补上，启动器会自动下载。一直没补上的话，欢迎反馈。

汉化版的成绩会上传排行榜吗？

选择翻译语言时，游戏会把记录标成 patched；要正常上榜，请在启动器的「游戏语言」中选择 English。

Windows 弹出「Windows 已保护你的电脑」怎么办？

启动器没有代码签名（需要每年付费购买），在下载量还不多之前，Windows SmartScreen 都会弹出这个警告。

角色名可以用中文吗？

暂时不行。游戏本身只允许英文字母和韩文作为角色名。
