安装

不需要手动修改任何游戏文件，全部交给启动器处理。请先关闭游戏。启动器的界面会使用你选择的语言。

  1. 先装好 D2 Survivors

    从 D2 Survivors 官网下载桌面版，按游戏的设置界面指定《暗黑破坏神 II》的安装位置，确认能正常进入游戏。

  2. 下载启动器

    下载 d2s-launcher.exe，放在任意文件夹即可，无需安装。

  3. 选择语言

    第一次打开会先出现语言界面，每种语言都用它自己的文字显示。点击你的语言、再点「→」，启动器的界面和游戏的翻译都会使用这个语言。

  4. 按设置向导完成三步

    ①「游戏」：找到 D2 Survivors（默认在 %LOCALAPPDATA%\Programs\D2 Survivors，装在别处就点「选择文件夹…」）。②「Diablo II」：查找你电脑上的《暗黑破坏神 II：狱火重生》或经典版，找不到也可以点「跳过」。③「完成」：可以点「在桌面创建快捷方式」，再点「启动游戏」。第一次会下载翻译，并自动备份原版 app.asar。

  5. 之后从快捷方式或启动器启动游戏

    默认每次启动都会获取最新的翻译（「设置」中的「启动时自动更新翻译」），游戏更新后也会自动重新应用。想换语言，在主界面的「游戏语言」中切换即可。

还原原版

  • 在启动器的「设置」中点「还原原版游戏」，游戏的 app.asar 就会换回原始文件。
  • 想暂时玩英文或韩文版，在「游戏语言」中选择 English 或 한국어 (원본) 再启动，就是没有修改过的原版。
  • 完全卸载：先还原原版，再删除启动器、桌面快捷方式和 %LOCALAPPDATA%\D2SurvivorsLauncher 文件夹。

桌面快捷方式

想自己创建快捷方式的话，把下面这行设为快捷方式的目标，双击即可直接用指定语言启动游戏，不会弹出启动器窗口。（启动器的「在桌面创建快捷方式」会打开窗口并直接启动游戏。）

d2s-launcher.exe --launch --lang zh-CN
--launch
应用语言并启动游戏
--play
打开启动器窗口并直接启动游戏（桌面快捷方式用的）
--lang <id>
指定语言：zh-TW、zh-CN、ja、de、fr、ru、pl，或原版 en、ko
--no-update
本次不检查翻译更新
--update
只更新翻译
--restore
还原原版
--self-update
更新启动器本身
--status
显示当前语言、游戏版本和翻译状态

使用方法

  • 点击书签后，游戏会以翻译后的语言重新打开（约一两秒）。游戏进行中也可以点，会先存档。首次按浏览器语言选择，之后记住上次使用的语言。
  • 再点一次书签可以在当前语言和英文之间切换；游戏里的语言设置也多了中文（繁体）、中文（简体）、日语、德语、法语、俄语和波兰语，可以直接切换。
  • 刷新页面会回到原版，需要再点一次书签。
  • 存档照常保存在浏览器里，不受影响。书签每次都从本站加载最新翻译，需要联网。

常见问题

这是官方翻译吗？

不是。这是玩家自制的非官方翻译，与 D2 Survivors 开发者及暴雪娱乐均无关。

这是开源的吗？

程序部分是。启动器、书签、网站和工具的源代码都在 GitHub 上，采用 MIT 许可。启动器由 GitHub Actions 从公开的源代码自动编译（编译记录），每个 Release 都附有 d2s-launcher.exe.sha256，可以自行核对。

翻译数据（词典）目前没有开放许可，保留所有权利，详见 dict/LICENSE。词典中沿用的官方译名归 Blizzard Entertainment 所有。

有简体中文版吗？

有，已正式推出。用语以《暗黑破坏神 II：狱火重生》官方简体中文为准，按大陆的说法翻译，不是从繁体中文直接转换。桌面版在启动器的语言界面选择「简体中文」即可；浏览器版点击书签后，会按浏览器语言自动选择简体中文，也可以在游戏的语言设置里切换。

可以在 Mac、Linux 或手机上玩吗？

可以。启动器目前只有 Windows 版；Mac、Linux 和手机请在浏览器里玩网页版，再用「浏览器版」页面里的书签切换成中文。

会影响我的存档吗？

不会。启动器只替换游戏文件夹中的 resources\app.asar，存档保存在其他位置，不会被读取或修改。替换前会先备份原版。

会影响我的存档吗？

不会。存档照常保存在浏览器里。书签只在当前打开的页面里替换游戏文字，不会留下任何修改，刷新页面就回到原版。

游戏更新后怎么办？

游戏更新会替换 app.asar，翻译会暂时消失。照常从启动器或快捷方式打开游戏就会重新应用。

如果新版本改动太大、修改规则无法匹配，启动器不会强行修改文件，而是先用原版启动游戏，并显示「游戏刚更新，翻译修正中」。翻译修好后，下次启动就会自动重新应用，什么都不用做。

游戏网页版更新后怎么办？

书签每次都会先检查修改规则是否匹配游戏的新版本。无法匹配时会提示「中文化需要更新」并且不会启动，原版游戏也不受影响；请先照常玩英文版，等这里更新即可。

为什么游戏语言菜单里的韩语变成了中文？

翻译借用了游戏内置的韩语语言位置，所以应用翻译后，菜单里的韩语会显示为所选语言的名称（例如「简体中文」）。想玩韩语版，在启动器中选择「한국어 (원본)」再启动。

手机上点书签没有反应？

Android Chrome 从书签列表点击不会执行，要在地址栏输入书签名称「D2 汉化」，再点击下方出现的书签。iPhone 请在游戏页面打开 Safari 的书签列表点击。

也请确认书签的网址已整个替换成书签代码，开头是 javascript:。

添加到主屏幕后可以用中文吗？

不行。从主屏幕打开的是全屏页面，没有地址栏，也没有书签可以点；翻译也不会保留到下次，刷新或重新打开都会回到原版。请在 Safari 或 Chrome 的标签页里玩，每次打开或刷新后再点一次书签。

为什么还有一些英文？

游戏里的文字都已翻译，也在游戏里检查过没有漏译。如果看到英文，通常是游戏刚更新、加入了新的文字；翻译会在之后的更新中补上，启动器会自动下载。一直没补上的话，欢迎反馈。

为什么还有一些英文？

游戏里的文字都已翻译，也在游戏里检查过没有漏译。如果看到英文，通常是游戏刚更新、加入了新的文字；翻译会在之后的更新中补上，书签每次都会加载最新的翻译。一直没补上的话，欢迎反馈。

Windows 弹出「Windows 已保护你的电脑」怎么办？

启动器没有代码签名（需要每年付费购买），在下载量还不多之前，Windows SmartScreen 都会弹出这个警告。

虽然没有签名，但启动器的源代码和编译过程都是公开的。

点击「更多信息」，再点击「仍要运行」即可，之后不会再提示。请只从本站或 GitHub Releases 下载；每个 Release 都附有 d2s-launcher.exe.sha256，可以用 certutil -hashfile d2s-launcher.exe SHA256 核对。

浏览器下载时如果提示该文件不常被下载，在下载列表的菜单里选择「保留」。

角色名可以用中文吗？

暂时不行。游戏本身只允许英文字母和韩文作为角色名。

翻译有错或游戏坏了，去哪里反馈？

错别字、漏译、书签或启动器的问题，请到汉化社区 Discord 反馈，那里也会发布最新消息。

翻译错误和程序问题也可以在 GitHub Issues 反馈。

游戏本身的问题（与翻译无关的）请到 D2 Survivors 游戏官方 Discord（英文）反馈。

想帮忙翻译或反馈错别字？

欢迎！所有语言都已正式推出，但翻译总有可以改进的地方。看到不自然的说法或错别字，特别欢迎母语玩家告诉我们。请到这里联系我们。
