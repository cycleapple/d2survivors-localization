インストール

ゲームのファイルを手で書き換える必要はなく、すべてランチャーが行います。先にゲームを終了してください。ランチャーの画面は今のところ繁体字中国語のみなので、下のボタン名はランチャーの表記のまま書いています。

Mac・Linux・スマホを使っている、またはブラウザで遊んでいる場合は

  1. まず D2 Survivors をインストール

    D2 Survivors 公式サイトからデスクトップ版をダウンロードし、ゲームの設定画面で『ディアブロ II』のインストール先を指定して、ゲームが起動することを確認します。

  2. ランチャーをダウンロード

    d2s-launcher.exe をダウンロードして、好きなフォルダに置きます。インストールは不要です。

  3. ランチャーを開く

    ランチャーは既定の場所 %LOCALAPPDATA%\Programs\D2 Survivors でゲームを探します。見つからない場合は「設定」（設定）を押してゲームのフォルダを指定します。

  4. 言語を選んで起動

    「遊戲語言」（ゲームの言語）で言語を選び、「啟動遊戲」（ゲームを起動）を押します。初回は翻訳をダウンロードし、元の app.asar を自動でバックアップします。

  5. 以後はランチャーから起動

    「啟動時自動更新翻譯」（起動時に翻訳を自動更新）にチェックを入れると、毎回最新の翻訳を取得し、ゲームのアップデート後も自動で適用し直します。

元に戻す

  • ランチャーで「還原原版」（元に戻す）を押すと、ゲームの app.asar が元のファイルに戻ります。
  • 一時的に英語版や韓国語版で遊びたいときは、「遊戲語言」で English または「한국어（原版）」を選んで起動します。
  • 完全に削除するには、元に戻したあと、ランチャーと %LOCALAPPDATA%\D2SurvivorsLauncher フォルダを削除します。

デスクトップのショートカット

ショートカットのリンク先を下のようにすると、ランチャーの画面を出さずに指定した言語でゲームを起動できます。

d2s-launcher.exe --launch --lang ja
--launch
言語を適用してゲームを起動
--lang <id>
言語を指定（例：ja、en、ko）
--no-update
今回は翻訳の更新を確認しない
--update
翻訳の更新だけ行う
--restore
元に戻す
--status
現在の言語、ゲームのバージョン、翻訳の状態を表示

ブックマークを追加

d2survivors.lol のブラウザ版で遊んでいますか？ ブックマークをひとつ追加するだけで中国語（繁体字）、中国語（簡体字）、日本語、ドイツ語、フランス語、ロシア語、またはポーランド語に切り替えられます。ランチャーと同じ翻訳を使い、インストールは不要、PC でもスマホでも使えます。

Windows でデスクトップ版を遊んでいる場合は

PC（Chrome、Edge、Firefox）

D2 日本語化 ← ブックマークバーへドラッグ

  1. Ctrl+Shift+B（Mac：⌘+Shift+B）でブックマークバーを表示します。
  2. 上の「D2 日本語化」ボタンをブックマークバーまでドラッグします。
  3. ゲームページを開き（「USE MY OWN FILES」か「HOSTED FILES」でゲームに入ります）、ブックマークバーの「D2 日本語化」をクリックします。

スマホ（Android Chrome、iPhone Safari）

javascript:import('https://cycleapple.github.io/d2survivors-localization/web/d2zh.js').then(m=>m.default()).catch(e=>alert('D2 Survivors Localization: '+e))
  1. 上のボタンでブックマークのコードをコピーします。
  2. このページをブックマークに追加し、そのブックマークを編集します。名前を「D2 日本語化」にして、URL をコピーしたコードにまるごと置き換えます。
  3. Android：ゲームページを開いてから、アドレスバーに「D2 日本語化」と入力し、下に出てくるブックマークをタップします（ブックマーク一覧からタップしても実行されません）。
  4. iPhone：ゲームページを開いてから、Safari のブックマーク一覧で「D2 日本語化」をタップします。

使い方

  • ブックマークを押すと、ゲームが翻訳された状態で開き直します（1〜2 秒）。プレイ中でも先にセーブするので大丈夫です。初回はブラウザの言語設定で言語を選び、以後は最後に使った言語を覚えています。
  • もう一度ブックマークを押すと、今の言語と英語を切り替えます。ゲームの OPTIONS → GAME OPTIONS の言語にも中国語（繁体字）、中国語（簡体字）、日本語、ドイツ語、フランス語、ロシア語、ポーランド語が追加され、そこから切り替えることもできます。
  • ページを再読み込みすると元のゲームに戻ります。もう一度ブックマークを押してください。
  • セーブデータはいつもどおりブラウザに保存され、影響はありません。ブックマークは毎回このサイトから最新の翻訳を読み込むので、ネット接続が必要です。

よくある質問

これは公式の翻訳ですか？

いいえ。プレイヤーが作った非公式の翻訳で、D2 Survivors の開発者とも Blizzard Entertainment とも関係ありません。

日本語版の完成度は？

今はベータ版です。ほとんどの文字は翻訳済みですが、まだ校正中のため、不自然な訳や英語のままの部分があります。見つけたらぜひ教えてください。

Mac、Linux、スマホでも遊べますか？

はい。ランチャーは今のところ Windows 版のみです。Mac・Linux・スマホではブラウザ版で遊び、「ブラウザ版」タブのブックマークで日本語に切り替えてください。

セーブデータに影響はありますか？

ありません。ランチャーが置き換えるのはゲームフォルダ内の resources\app.asar だけで、置き換える前に元のファイルをバックアップします。セーブデータは別の場所にあり、読み込みも変更もしません。

セーブデータに影響はありますか？

ありません。セーブデータはいつもどおりブラウザに保存されます。ブックマークは開いているページの中でゲームの文字を差し替えるだけで、何も残しません。再読み込みすると元に戻ります。

ゲームがアップデートされたら？

ゲームのアップデートで app.asar が置き換わるため、翻訳は一時的に消えます。いつもどおりランチャーから起動すれば、また適用されます。

新しいバージョンの変更が大きく、書き換えルールが合わない場合、ランチャーは無理に書き換えずにエラーを表示します。その間は「還原原版」で元に戻していつもどおり遊び、翻訳の更新を待ってください。

ブラウザ版のゲームがアップデートされたら？

ブックマークは毎回、書き換えルールが新しいバージョンに合うかを先に確認します。合わない場合は「更新が必要」と表示して起動せず、元のゲームにも影響しません。翻訳が更新されるまで英語版で遊んでください。

ゲーム内の言語メニューで、韓国語が「日本語」になっているのはなぜ？

翻訳はゲームに組み込まれている韓国語の枠を借りているため、適用すると言語メニューの韓国語が選んだ言語の名前になります。韓国語で遊びたいときは、ランチャーで「한국어（原版）」を選んで起動してください。

スマホでブックマークを押しても何も起きない

Android の Chrome では、ブックマーク一覧からタップしても実行されません。アドレスバーにブックマークの名前「D2 日本語化」を入力し、下に出てくるブックマークをタップしてください。iPhone は、ゲームページを開いた状態で Safari のブックマーク一覧からタップします。

ブックマークの URL がコードにまるごと置き換わっていて、javascript: で始まっているかも確認してください。

まだ英語のところがあるのはなぜ？

UI・スキル・アイテム・モンスターはほとんど翻訳済みですが、パッチノートや長めのスキル説明の一部は翻訳中で、それまでは英語で表示されます。ランチャーが自動で更新するので、翻訳が終わりしだい反映されます。

まだ英語のところがあるのはなぜ？

UI・スキル・アイテム・モンスターはほとんど翻訳済みですが、パッチノートや長めのスキル説明の一部は翻訳中で、それまでは英語で表示されます。ブックマークは毎回最新の翻訳を読み込むので、翻訳が終わりしだい反映されます。

「Windows によって PC が保護されました」と表示されたら？

ランチャーにはコード署名がありません（署名の証明書は毎年費用がかかります）。そのため、ダウンロードした人が十分に増えるまでは Windows SmartScreen がこの警告を出します。

「詳細情報」を押してから「実行」を押してください。次からは表示されません。ダウンロードはこのサイトか GitHub Releases からだけにしてください。各リリースには d2s-launcher.exe.sha256 が付いていて、certutil -hashfile d2s-launcher.exe SHA256 で照合できます。

ブラウザが「このファイルは一般的にダウンロードされていません」と表示した場合は、ダウンロードのメニューから「保存」を選んでください。

キャラクター名に日本語は使えますか？

今のところ使えません。ゲーム自体がキャラクター名に英字と韓国語しか使えない仕様です。

翻訳の誤りや不具合はどこに報告すればいい？

誤字・訳抜け・ブックマークやランチャーの不具合は、翻訳コミュニティの Discord に報告してください。最新情報もそこでお知らせします。

ゲーム自体の不具合（翻訳と関係ないもの）は D2 Survivors のゲーム公式 Discord（英語）に報告してください。

翻訳を手伝ったり、誤字を報告したりできますか？

大歓迎です！ 繁体字中国語以外の言語はまだ制作中かベータ版で、特にネイティブの方の校正が助かります。こちらからご連絡ください。
