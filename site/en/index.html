Install

You never edit game files by hand; the launcher does it all. Close the game first.

On Mac, Linux, or a phone, or playing in the browser?

  1. Install D2 Survivors first

    Download the desktop app from the official D2 Survivors site, point its setup screen at your Diablo II install, and make sure the game runs.

  2. Download the launcher

    Download d2s-launcher.exe and put it in any folder. No installation needed.

  3. Open the launcher

    It looks for the game in %LOCALAPPDATA%\Programs\D2 Survivors. If the game is elsewhere, click 設定 (Settings) and set the game folder.

  4. Pick a language and play

    Choose a language under 遊戲語言 (Game language) and click 啟動遊戲 (Launch game). The first run downloads the translation and backs up the original app.asar.

  5. Always start from the launcher

    With 啟動時自動更新翻譯 (auto-update) checked, every launch fetches the latest translation, and it re-applies itself after game updates.

Restore the original

  • Click 還原原版 (Restore original) in the launcher to put the original app.asar back.
  • To play in English or Korean for a while, pick English or 한국어（原版） and launch.
  • To remove everything: restore the original, then delete the launcher and the %LOCALAPPDATA%\D2SurvivorsLauncher folder.

Desktop shortcut

Use this as a shortcut target to start the game in a given language without opening the launcher window.

d2s-launcher.exe --launch --lang zh-TW
--launch
Apply the language and start the game
--lang <id>
Language to use, e.g. zh-TW, en, ko
--no-update
Skip the translation update this time
--update
Only update translations
--restore
Restore the original
--status
Show the current language, game version, and translation status

Get the bookmark

Playing in the browser at d2survivors.lol? One bookmark switches the game to Chinese (Traditional), Chinese (Simplified), Japanese, German, French, or Russian, using the same translation as the launcher. Nothing to install, on computers and phones alike.

Playing the desktop app on Windows?

Computer (Chrome, Edge, Firefox)

D2 Localization ← drag to the bookmarks bar

  1. Press Ctrl+Shift+B (Mac: ⌘+Shift+B) to show the bookmarks bar.
  2. Drag the “D2 Localization” button above onto the bookmarks bar.
  3. Open the game page (pick USE MY OWN FILES or HOSTED FILES to get into the game), then click “D2 Localization” in the bookmarks bar.

Phone (Android Chrome, iPhone Safari)

javascript:import('https://cycleapple.github.io/d2survivors-localization/web/d2zh.js').then(m=>m.default()).catch(e=>alert('D2 Survivors Localization: '+e))
  1. Tap the button above to copy the bookmark code.
  2. Bookmark this page, then edit that bookmark: name it “D2 Localization” and replace its whole address with the copied code.
  3. Android: on the game page, type “D2 Localization” in the address bar and tap the bookmark that appears below it (tapping it in the bookmarks list doesn’t run it).
  4. iPhone: on the game page, tap “D2 Localization” in Safari’s bookmarks.

How it works

  • The bookmark restarts the game translated, which takes a second or two. It saves first, so it’s fine mid-run. The first time, it picks a language from your browser settings; after that it remembers the last one you used.
  • Use the bookmark again to switch between the current language and English. The game’s OPTIONS → GAME OPTIONS language setting also gains Chinese (Traditional), Chinese (Simplified), Japanese, German, French, and Russian.
  • Reloading the page brings back the original game; use the bookmark again.
  • Saves stay in your browser as usual. The bookmark loads the latest translation from this site each time, so it needs a connection.

FAQ

Is this an official translation?

No. It is an unofficial fan translation, not affiliated with the D2 Survivors developers or Blizzard Entertainment.

Can I play on Mac, Linux, or a phone?

Yes. The launcher is Windows-only for now; on Mac, Linux, and phones, play the web version and use the bookmark from the Browser tab.

Will it touch my saves?

No. The launcher only replaces resources\app.asar in the game folder, after backing up the original. Saves live elsewhere and are never read or changed.

Will it touch my saves?

No. Saves stay in your browser as usual. The bookmark only swaps the game text in the page you have open and leaves nothing behind; reloading brings back the original.

What happens when the game updates?

A game update replaces app.asar, so the translation disappears until you start the game from the launcher again, which re-applies it.

If a new version changed too much for the patch rules to match, the launcher reports an error instead of forcing the change. Restore the original and play as usual until the translation catches up.

What happens when the web game updates?

The bookmark checks that its patch rules still match the new version every time. If they don’t, it says the translation needs an update and doesn’t start, leaving the original game untouched. Play in English until it’s updated here.

Why does the in-game language menu show my language instead of Korean?

The translation borrows the game's built-in Korean language slot, so after applying it the menu shows the name of the language you picked (for example 简体中文) where Korean used to be. To play in Korean, pick 한국어（原版） in the launcher.

Nothing happens when I tap the bookmark on my phone?

Android Chrome doesn’t run bookmarks tapped in the bookmarks list: type the bookmark name “D2 Localization” in the address bar and tap the bookmark that appears below. On iPhone, open Safari’s bookmarks while on the game page and tap it there.

Also check that the bookmark’s whole address was replaced with the bookmark code, starting with javascript:.

Why is some text still in English?

Almost all UI, skills, items, and monsters are translated. Patch notes and some longer skill descriptions are still in progress and show in English for now; they arrive automatically through launcher updates.

Why is some text still in English?

Almost all UI, skills, items, and monsters are translated. Patch notes and some longer skill descriptions are still in progress and show in English for now; the bookmark always loads the latest translation, so they appear as soon as they’re done.

Windows says “Windows protected your PC”. What do I do?

The launcher isn’t code-signed (a signing certificate costs money every year), so Windows SmartScreen warns about it until enough people have downloaded it.

Click More info, then Run anyway; Windows won’t ask again. Only download it from this site or GitHub Releases. Every release includes d2s-launcher.exe.sha256, which you can check with certutil -hashfile d2s-launcher.exe SHA256.

If your browser says the file isn’t commonly downloaded, choose Keep from the download’s menu.

Can I use Chinese in character names?

Not yet. The game itself only allows English letters and Korean in character names.

Where do I report a translation error or something broken?

Typos, missing translations, and problems with the bookmark or launcher go to the localization community Discord, where news is posted too.

Problems with the game itself (not caused by the translation) go to the official D2 Survivors Discord.

How can I help translate or report a typo?

Gladly! Every language other than Traditional Chinese is still in progress or in beta, and native speakers are especially welcome to help review. Get in touch here.
