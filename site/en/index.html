Install

You never edit game files by hand; the launcher does it all. Close the game first. The launcher shows its screens in the language you pick, so the button names below may read differently on yours.

  1. Install D2 Survivors first

    Download the desktop app from the official D2 Survivors site, point its setup screen at your Diablo II install, and make sure the game runs.

  2. Download the launcher

    Download d2s-launcher.exe and put it in any folder. No installation needed.

  3. Pick your language

    The first screen lists every language, each written in its own script. Click yours, then “→”: the launcher and the game translation both use that language from then on.

  4. Follow the three-step setup

    ① “Game”: the launcher finds D2 Survivors (by default in %LOCALAPPDATA%\Programs\D2 Survivors; if it’s elsewhere, use “Choose folder…”). ② “Diablo II”: it looks for your Diablo II: Resurrected or classic Diablo II; you can “Skip” this if it isn’t found. ③ “Done”: optionally click “Create a desktop shortcut”, then “Play”. The first run downloads the translation and backs up the original app.asar.

  5. Play from the shortcut or the launcher

    By default every start fetches the latest translation (“Update translations on start” in “Settings”), and it re-applies itself after game updates. To switch languages, change “Game language” on the main screen.

Restore the original

  • In the launcher, open “Settings” and click “Restore the original game” to put the original app.asar back.
  • To play in English or Korean for a while, pick English or 한국어 under “Game language” and launch: that runs the untouched original.
  • To remove everything: restore the original, then delete the launcher, its desktop shortcut, and the %LOCALAPPDATA%\D2SurvivorsLauncher folder.

Desktop shortcut

To make your own shortcut, use this line as its target: it starts the game in the given language without opening the launcher window. (The shortcut from “Create a desktop shortcut” opens the window and starts the game right away.)

d2s-launcher.exe --launch --lang zh-TW
--launch
Apply the language and start the game
--play
Open the launcher window and start the game right away (used by the desktop shortcut)
--lang <id>
Language: zh-TW, zh-CN, ja, de, fr, ru, pl, or the original en, ko
--no-update
Skip the translation update this time
--update
Only update translations
--restore
Restore the original
--self-update
Update the launcher itself
--status
Show the current language, game version, and translation status

How it works

  • Use the bookmark on the d2survivors.lol home page and the game starts translated right away. The home page uses less memory and loads faster, which is especially worth it on phones. It also works on the game page (/play/): the game restarts translated, saving first if you’re mid-run.
  • The bookmark from this page picks a language from your browser settings the first time and then remembers the last one you used; the bookmark from any other language’s page always opens that language. To switch language, install the bookmark from that language’s page; if you installed it before, reinstall it to lock in a language. The game’s OPTIONS → GAME OPTIONS language setting also gains Chinese (Traditional), Chinese (Simplified), Japanese, German, French, Russian, and Polish, but on a phone it’s best to switch with the bookmark.
  • Using the bookmark again takes you back to the original English game page. Reloading also brings back the original; use the bookmark again to play translated.
  • If your phone stutters, gets hot, or keeps reloading the game, turn on “Power saving graphics” under OPTIONS → VIDEO OPTIONS in the game: it lowers the resolution, so the game runs smoother and cooler, with a slightly softer picture.
  • Saves stay in your browser as usual. The bookmark loads the latest translation from this site each time, so it needs a connection.

FAQ

Is this an official translation?

No. It is an unofficial fan translation, not affiliated with the D2 Survivors developers or Blizzard Entertainment.

Is this open source?

The code is. The source for the launcher, the bookmark, this website, and the tools is on GitHub under the MIT License. The launcher is built automatically from that public source by GitHub Actions (build history), and every release includes d2s-launcher.exe.sha256 so you can check it yourself.

The translation data (the dictionaries) is not openly licensed yet; all rights are reserved, see dict/LICENSE. The official terms used in them belong to Blizzard Entertainment.

Can I play on Mac, Linux, or a phone?

Yes. The launcher is Windows-only for now; on Mac, Linux, and phones, play the web version and use the bookmark from the Browser tab.

Will it touch my saves?

No. The launcher only replaces resources\app.asar in the game folder, after backing up the original. Saves live elsewhere and are never read or changed.

Will it touch my saves?

No. Saves stay in your browser as usual. The bookmark only swaps the game text in the page you have open and leaves nothing behind; reloading brings back the original.

What happens when the game updates?

A game update replaces app.asar, so the translation disappears until you start the game from the launcher or its shortcut again, which re-applies it.

If a new version changed too much for the patch rules to match, the launcher doesn’t force anything: it starts the original game and says the translation is being fixed. Once it’s fixed, the next start applies it again automatically; you don’t need to do anything.

What happens when the web game updates?

The bookmark checks that its patch rules still match the new version every time. If they don’t, it says the translation needs an update and doesn’t start, leaving the original game untouched. Play in English until it’s updated here.

Why does the in-game language menu show my language instead of Korean?

The translation borrows the game's built-in Korean language slot, so after applying it the menu shows the name of the language you picked (for example 简体中文) where Korean used to be. To play in Korean, pick 한국어 (원본) in the launcher.

Nothing happens when I tap the bookmark on my phone?

Android Chrome doesn’t run bookmarks tapped in the bookmarks list: type the bookmark name “D2 Localization” in the address bar and tap the bookmark that appears below. On iPhone, open Safari’s bookmarks while on the home page or the game page and tap it there.

Also check that the bookmark’s whole address was replaced with the bookmark code, starting with javascript:.

Does the game reload by itself partway through on my phone?

Usually the phone ran low on memory and the browser reloaded the tab. To help:

  • Use the bookmark on the d2survivors.lol home page instead of opening the game page first; otherwise the original game loads first and keeps holding memory.
  • Turn on “Power saving graphics” under OPTIONS → VIDEO OPTIONS in the game.
  • Close other tabs.

After a reload, use the bookmark again to carry on; your progress is whatever the game itself saved.

Does it work if I add the game to my home screen?

No. The home screen version opens full screen, with no address bar or bookmarks to tap, and the translation doesn’t carry over: reloading or reopening brings back the original. Play in a Safari or Chrome tab instead, and tap the bookmark again each time you open or reload the game.

Why is some text still in English?

All of the game’s text is translated and has been checked in game for anything left untranslated. If you see English, the game has probably just been updated with new text; a later translation update fills it in, and the launcher downloads it automatically. If it stays in English, please let us know.

Why is some text still in English?

All of the game’s text is translated and has been checked in game for anything left untranslated. If you see English, the game has probably just been updated with new text; a later translation update fills it in, and the bookmark always loads the latest translation. If it stays in English, please let us know.

Are runs sent to the leaderboard when the game is translated?

In the browser, yes. With the bookmark, runs are sent to the leaderboard as usual, Normal and Hardcore alike, and each record shows the language you actually played in (for example zh-TW).

On desktop, picking a translated language makes the game mark records as patched; to show up normally, pick English under “Game language” in the launcher.

Windows says “Windows protected your PC”. What do I do?

The launcher isn’t code-signed (a signing certificate costs money every year), so Windows SmartScreen warns about it until enough people have downloaded it.

It isn’t signed, but the launcher’s source code and build process are both public.

Click More info, then Run anyway; Windows won’t ask again. Only download it from this site or GitHub Releases. Every release includes d2s-launcher.exe.sha256, which you can check with certutil -hashfile d2s-launcher.exe SHA256.

If your browser says the file isn’t commonly downloaded, choose Keep from the download’s menu.

Can I use Chinese in character names?

Not yet. The game itself only allows English letters and Korean in character names.

Where do I report a translation error or something broken?

Typos, missing translations, and problems with the bookmark or launcher go to the localization community Discord, where news is posted too.

You can also report translation errors and bugs in the code on GitHub Issues.

Problems with the game itself (not caused by the translation) go to the official D2 Survivors Discord.

How can I help translate or report a typo?

Gladly! Every language is fully released, but a translation can always get better. If you spot awkward wording or a typo, especially in your native language, please tell us. Get in touch here.
