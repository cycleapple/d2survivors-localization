# D2 Survivors Localization（非公式）

[English](../../README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | **日本語** | [Deutsch](README.de.md) | [Français](README.fr.md) | [Русский](README.ru.md) | [Polski](README.pl.md)

[D2 Survivors](https://d2survivors.lol/)（Diablo 2 Survivors）の有志による非公式翻訳です。対応言語：繁體中文、简体中文、日本語、Deutsch、Français、Русский、Polski。

**サイト：** https://cycleapple.github.io/d2survivors-localization/ja/ · **Discord：** https://discord.gg/QMBbTHSsaK

- **デスクトップ版**（Windows）：[ランチャー](https://github.com/cycleapple/d2survivors-localization/releases/latest/download/d2s-launcher.exe)をダウンロードし、言語を選んで「プレイ」を押すだけ。最新の翻訳を自動でダウンロードしてゲームに適用します。ゲームが自動更新されても、次にランチャーから起動すれば翻訳が自動で再適用されます。
- **ブラウザー版**（PC・スマホ）：d2survivors.lol のブラウザー版でブックマークを押すと日本語に切り替わります。もう一度押すと英語に戻ります。

画面の上に文字を重ねるのではなく、ゲーム内蔵の翻訳機能（韓国語辞書の枠）をそのまま使っているので、UI・アイテム・スキル・説明文まで翻訳されます。アイテム・スキル・モンスター・地名は『ディアブロ II リザレクテッド』の公式訳を使っています。

## ランキング

- ブラウザー版では、翻訳を適用している間はランキングのスコアを送信しません。
- デスクトップ版の翻訳版は、ゲーム側で patched と表示されます。ランキングに挑戦するときは、ランチャーで English を選べば完全なオリジナルに戻ります。
